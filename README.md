# Mad Lyricist 🎶

A text-based interactive C# songwriting generator.

## 📌 Features
- Captures multiple grammatical inputs (nouns, verbs, adjectives, places, time of day).
- Dynamically structures lyrics inspired by classic themes.
- Uses C# logical (`&&`, `||`) and comparison (`==`, `!=`) operators to alter stanzas.
- Controlled via a primary `while` loop allowing continuous song generation.

## 🛠️ Requirements & Tech Stack
- .NET / C#
- Visual Studio Code

## 🚀 How to Run
```bash
dotnet run
```
